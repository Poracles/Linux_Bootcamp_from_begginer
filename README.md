### Краткая информация о Pet-Project:

#### Проект: Развертывание отказоустойчивого веб-сервера (LEMP Stack).

- Задача: Развернуть защищенную инфраструктуру для хостинга CMS WordPress с 
нуля. 

- План действий: 
    - Спроектировать дисковую подсистему на базе Software RAID 10 и LVM для 
гибкого управления пространством и надежности данных. 

    - Настроить веб-сервер Nginx (SSL/TLS, ограничение доступа к 
админ-панелям по IP). 

    - Развернуть и оптимизировать MariaDB: разделить пользователей БД 
(приложение vs бэкап), настроить права доступа. 

    - Реализовать систему безопасности: настроить UFW (политика Default Deny), 
отключить вход root по SSH, настроить аутентификацию по ключам. 

    - Автоматизировать резервное копирование: написать Bash-скрипт (бэкап 
файлов + дамп базы + ротация старых копий) и поставить на выполнение в 
Cron. 


- Для того что бы посмотреть отчет о практическом выполненнии проекта перейдите в >>finish_quest>>report.md

- Вся информация о курсе на русском языке находится в README_RUS.md


- Благодарю за внимание.
