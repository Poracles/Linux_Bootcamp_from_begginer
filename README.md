### Краткая информация о Pet-Project:

#### Проект: Развертывание отказоустойчивого веб-сервера (LEMP Stack).

- Задача: Развернуть защищенную инфраструктуру для хостинга CMS WordPress с 
нуля. 

- Реализация: 
    - Спроектировал дисковую подсистему на базе Software RAID 10 и LVM для 
гибкого управления пространством и надежности данных. 

    - Настроил веб-сервер Nginx (SSL/TLS, ограничение доступа к 
админ-панелям по IP). 

    - Развернул и оптимизировал MariaDB: разделил пользователей БД 
(приложение vs бэкап), настроил права доступа. 

    - Реализовал систему безопасности: настроил UFW (политика Default Deny), 
отключил вход root по SSH, настроил аутентификацию по ключам. 

    - Автоматизировал резервное копирование: написал Bash-скрипт (бэкап 
файлов + дамп базы + ротация старых копий) и поставил на выполнение в 
Cron. 

    - Результат: Полностью работоспособный, защищенный веб-сервер, 
выдерживающий отказ одного диска и автоматизирующий рутинные задачи.
